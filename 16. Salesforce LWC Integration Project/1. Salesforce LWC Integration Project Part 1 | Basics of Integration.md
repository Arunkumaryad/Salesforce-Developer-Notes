# Salesforce LWC Integration Project - Part 1

# Basics of Integration

## Overview

Integration is one of the most important topics in Salesforce Development. Almost every real-world Salesforce project communicates with external systems such as banking applications, payment gateways, ERP systems, HRMS, inventory systems, government APIs, Google Maps, or third-party applications.

In Salesforce, Integration allows data and business processes to be shared between Salesforce and external applications through APIs.

This document covers the fundamental concepts of Salesforce Integration before learning REST APIs, Apex Callouts, Named Credentials, Authentication, and External Services.

---

# What is Integration?

## Actual Definition (From Notes)

> **Integration is needed to connect two or more systems together to share data, user interfaces, business logic etc.**

---

## Simple Definition

Integration is the process of connecting Salesforce with another application so that both systems can communicate and exchange information.

Instead of working independently, both systems work together by sending requests and receiving responses.

---

# Why Do We Need Integration?

In real-world projects, Salesforce is rarely the only application used by a company.

Organizations often use multiple systems such as:

- ERP Software
- Banking Systems
- HRMS
- Inventory Management
- Payment Gateway
- Shipping Applications
- Government APIs
- Marketing Platforms

Integration allows these systems to communicate with Salesforce automatically.

### Example

Customer places an order on a website.

Instead of manually entering the information into Salesforce:

Website → API → Salesforce

The customer information is automatically created inside Salesforce.

---

# Basic Integration Architecture

```
System A (Salesforce)
        │
        │ Callout / Request
        ▼
 Internet
        │
        ▼
API (Web Service)
(System B)
        │
     Database
        │
        ▼
Response
        │
        ▼
Salesforce
```

Salesforce sends a **Request** to an API.

The API processes the request, retrieves or updates data, and sends back a **Response**.

---

# Request and Response

According to the notes:

## Request

> **Request = Method + Parameters + Body + Headers**

A Request contains:

- HTTP Method
- Parameters
- Request Body
- Headers

Example

```
GET /accounts
```

or

```
POST /accounts
```

---

## Response

> **Response = Status Code + Body + Headers**

A Response contains:

- HTTP Status Code
- Response Body
- Response Headers

Example

```
Status : 200 OK

{
   "Name":"John"
}
```

# Types of Integration

According to the notes, there are three major types of Integration.

---

## 1. Data Integration

### Actual Definition

> **Sharing some data e.g. customer accounts data.**

### Simple Explanation

Only data is exchanged between two systems.

Example:

- Customer Records
- Account Records
- Contact Records
- Orders

---

## 2. User Interface Integration

### Actual Definition

> **Sharing user interface like Google Maps widget.**

### Simple Explanation

Instead of copying data, another application's UI is embedded inside Salesforce.

Example

- Google Maps
- Payment Window
- Chat Widget
- Calendar

---

## 3. Business Logic Integration

### Actual Definition

> **Sharing some business logic like calculating interest.**

### Simple Explanation

Instead of sharing data, another application performs business calculations.

Example

- Tax Calculation
- EMI Calculation
- Currency Conversion
- Insurance Premium

---

# Directions of Integration

Integration can happen in two directions.

---

## 1. Inbound Integration

### Actual Definition

> **An external system initiates contact with Salesforce.**

### Example

```
External System
       │
       ▼
 Salesforce
```

The external application sends data to Salesforce.

Example:

Website creates records inside Salesforce.

---

## 2. Outbound Integration

### Actual Definition

> **Salesforce initiates contact with an external system.**

### Example

```
Salesforce
     │
     ▼
External System
```

Salesforce sends a request to another application.

Example

Salesforce sends customer details to an ERP system.

---

# What is Callout (Request)?

## Actual Definition

> **Callout is a request made to API which in turn communicates with other system to get data.**

---

## Simple Definition

A Callout is when Salesforce sends an HTTP request to another application using an API.

Example

```
Salesforce
      │
HTTP Request
      ▼
REST API
      │
HTTP Response
      ▼
Salesforce
```

---

# What is Endpoint (API Endpoint)?

## Actual Definition

> **Endpoint is a specific URL or address where API is available.**

---

## Simple Definition

Endpoint is simply the URL of an API.

Example

```
https://api.company.com/accounts
```

Here,

```
https://api.company.com/accounts
```

is the Endpoint.

---

# What is an API?

## Actual Definition

> **API stands for Application Programming Interface.**

> **API can be defined as set of rules or protocols that allow different software applications to communicate and interact with each other.**

---

## Simple Definition

API acts as a messenger between two applications.

One application sends a request.

The other application processes it and returns a response.

---

# What are Web Services?

## Actual Definition

> **API which are available over Internet, are called as Web Services.**

> **Web Services are a subset of APIs.**

---

## Simple Definition

Every Web Service is an API.

But every API is not necessarily a Web Service.

Web Services work over the Internet.

---

# Difference between API and Web Services

According to the notes

| API | Web Service |
|------|-------------|
| Can work locally or over network | Works over Internet |
| May or may not be Web Service | Always an API |
| Larger concept | Subset of APIs |

---

# Difference between SOAP and REST

| SOAP | REST |
|-------|------|
| Simple Object Access Protocol | Representational State Transfer |
| Supports XML only | Supports HTML, XML, JSON |
| Uses HTTP, HTTPS, SMTP, UDP etc. | Uses HTTP and HTTPS |
| Requires more bandwidth | Requires less bandwidth |
| More Secure | Less Secure |
| Requires WSDL | Accessed through URL |

---

# REST Web Service Methods

| Method | Purpose |
|----------|------------------------------|
| GET | Retrieve data |
| POST | Insert new data |
| PUT | Insert new data or update existing data |
| PATCH | Update existing data |
| DELETE | Delete existing data |

---

# Response Codes (HTTP Status Codes)

According to the notes:

### 1xx

Informational response.

The request was received and the process is continuing.

---

### 2xx

Successful.

The request was successfully received, understood and accepted.

---

### 3xx

Redirection.

Further action is required to complete the request.

---

### 4xx

Client Error.

The request contains bad syntax or cannot be fulfilled.

---

### 5xx

Server Error.

The server failed to fulfill a valid request.

---

# Common HTTP Status Codes

| Code | Meaning | Description |
|------|----------|-------------|
| 200 | OK | Request succeeded |
| 400 | Bad Request | Server could not understand request |
| 401 | Unauthorized | Authentication required |
| 403 | Forbidden | Access denied |
| 404 | Not Found | Resource or Endpoint not found |
| 500 | Internal Server Error | Server-side error |
| 503 | Service Unavailable | Server temporarily unavailable |

# Interview Questions

### What is Integration?

Connecting two or more systems to share data, user interface, or business logic.

---

### What is an API?

Application Programming Interface that enables communication between software applications.

---

### What is a Callout?

An HTTP request sent from Salesforce to an external system.

---

The URL where an API is available.

---

A Web Service is an API that is available over the Internet.

---

SOAP uses XML and WSDL, whereas REST is lightweight, supports JSON/XML, and uses HTTP methods.

---

GET

### Which REST method creates records?

POST

### Which REST method updates records?

PUT or PATCH

---

### Which REST method deletes records?

DELETE
