# 📖 Overview

Integration is one of the most important topics in Salesforce Development. In this project, we learn how to consume an external REST API from Salesforce using Apex.

Before writing Apex code, we first test the API using **Postman**, then configure **Remote Site Settings** in Salesforce so that Salesforce can securely communicate with the external server.

In this project we use the **CollectAPI Gas Price API** as an example.

# 📖 Actual Definition (Based on the Video)

### Remote Site Settings

Remote Site Settings allow Salesforce to communicate securely with an external website or REST API.

Salesforce blocks callouts to unknown external URLs by default. To allow a callout, the external URL must first be added to **Remote Site Settings**.

---

### Postman

Postman is an API development and testing tool that allows developers to send HTTP requests to REST APIs without writing any code.

It helps developers verify API requests and responses before implementing them in Salesforce.

---

### Apex REST Integration

Apex REST Integration is the process of consuming or exposing REST APIs using Apex classes.

In this project, Apex is consuming data from an external REST API using an HTTP Callout.

---

# 💡 Simple Definition

Imagine Salesforce wants to talk to another application.

Salesforce first asks:

> "Is this website trusted?"

If the website is listed in **Remote Site Settings**, Salesforce allows the communication.

Otherwise, Salesforce blocks it.

# 🔷 Step 2 — Configure Remote Site Settings

Before Apex can call an external API,

Salesforce must trust that URL.

Go to

```
Setup

↓

Remote Site Settings

↓

New
```

Fill the following details

| Field | Value |
|--------|---------|
| Remote Site Name | IMDBAPI (or any meaningful name) |
| Remote Site URL | https://api.collectapi.com |
| Active | ✔ |

Save.

Now Salesforce allows callouts to this URL.

---

# Why Remote Site Settings are Required

Salesforce follows a strict security model.

Without Remote Site Settings,

this code

```apex
HttpRequest req = new HttpRequest();
req.setEndpoint('https://api.collectapi.com');
```

will throw an exception.

Typical error

```
Unauthorized endpoint
```

After adding Remote Site Settings,

the callout succeeds.

# 🔷 Step 3 — Write Apex Callout

The basic flow is

```

↓

↓

↓

```

---

# Sample Apex Code

```apex
Http http = new Http();

HttpRequest request = new HttpRequest();

request.setMethod('GET');

request.setEndpoint(
'https://api.collectapi.com/gasPrice/stateUsaPrice?state=WA'
);

request.setHeader(
'authorization',
'apikey YOUR_API_KEY'
);

HttpResponse response = http.send(request);

System.debug('Response: ' + response.getBody());
```

---

# Understanding the Code

### Create HTTP Object

```apex
Http http = new Http();
```

Responsible for sending requests.

---

### Create Request

```apex
HttpRequest request = new HttpRequest();
```

Creates a new HTTP request.

---

### Set HTTP Method

```apex
request.setMethod('GET');
```

We are fetching data.

---

### Set Endpoint

```apex
request.setEndpoint(URL);
```

Defines which API Salesforce should call.

---

### Set Header

```apex
request.setHeader('authorization','apikey...');
```

Passes the API key.

---

### Send Request

```apex
HttpResponse response = http.send(request);
```

Executes the API call.

---

### Read Response

```apex
response.getBody();
```

Returns the JSON response.

# Best Practices

✅ Always test APIs in Postman before Apex.

✅ Never hardcode API Keys in production code.

✅ Store sensitive credentials securely (Named Credentials or protected configuration).

✅ Always handle exceptions.

✅ Check the HTTP Status Code.

✅ Parse JSON properly.

✅ Log responses only for debugging.

# Key Takeaways

- Integration allows Salesforce to communicate with external systems.
- Postman is the best tool for testing REST APIs before coding.
- Remote Site Settings are mandatory for Apex callouts (unless using newer alternatives such as Named Credentials).
- Apex uses `Http`, `HttpRequest`, and `HttpResponse` to consume REST APIs.
- API keys are typically passed in request headers for authentication.
- JSON responses can be retrieved using `response.getBody()` and processed further.
- Debug Logs help verify that the API returned the expected data.
